# Welcome to the Kali Linux Ethical Hacking Lab

In this interactive scenario, you will transform an Ubuntu host into a fully working Kali Linux-style penetration testing environment. We do this by adding the official Kali Linux repositories directly to the system and installing hundreds of ethical hacking tools natively, no Docker required.

## What You Will Learn

- How to safely add Kali Linux repositories to an Ubuntu system
- How to use APT pinning to prevent package conflicts
- How to install and verify essential penetration testing tools
- How to perform basic reconnaissance and vulnerability research
- How to navigate the Kali Linux tool ecosystem safely and legally

## Prerequisites

- Basic familiarity with Linux command line
- Curiosity about cybersecurity and ethical hacking

## Important Legal Notice

> This scenario is for **educational purposes only**. Always ensure you have explicit written permission before testing any system you do not own. Unauthorized access to computer systems is illegal in most jurisdictions.

## How It Works

1. A background script automatically adds Kali's GPG key and repository
2. APT pinning is configured so Kali packages do not override Ubuntu system packages
3. Over 300 penetration testing tools are installed directly on the host
4. You use the tools exactly as you would on a native Kali Linux installation

## Estimated Time

- Setup: ~5-8 minutes (automated in the background)
- Hands-on practice: ~15-20 minutes
